## How to read these cases

Each case follows the same structure:

**Context → Challenge → Architecture → Engineering decisions → Stack → My contribution → Outcome**

The objective is not to publish internal implementation details. It is to make the engineering thinking and breadth of work visible.

### Portfolio principles

- **Architecture over screenshots** — show how the system is shaped, not only how it looks.
- **Business context matters** — engineering decisions should connect to real operational needs.
- **Security by design** — tenancy, authorization, traceability and failure modes are part of the architecture.
- **Private code stays private** — proprietary repositories are represented through safe public case studies.
